# Grundtone Studio

Private commercial SaaS for configuring Grundtone design systems.

Organizations sign up, create projects (design system instances), configure design tokens through a
web UI, and consume their tokens in any Vue/Nuxt/React app via the `@grundtone/saas-client` npm
package + an API key.

See [docs/MVP.md](./docs/MVP.md) for the full plan.
